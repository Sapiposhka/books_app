# Книжный рекомендатель

Десктопное приложение для подбора книг на основе предпочтений пользователя и его текущего настроения.

Интерфейс разработан на PyQt6. Данные книг, пользователей и лайков хранятся в SQLite. Ответы анкет сохраняются в JSON.

## Установка

Для работы приложения необходим Python 3.

### Windows (PowerShell)

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

### macOS

Создайте виртуальное окружение:

```bash
python3 -m venv .venv
```

Активируйте его:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
python3 -m pip install -r requirements.txt
```

## Запуск

После установки зависимостей запустите приложение из корневой папки проекта:

```bash
python main.py
```

При запуске откроется окно авторизации, в котором можно войти в существующий аккаунт или зарегистрировать новый.

## Структура проекта

- `main.py` — точка входа.
- `db/` — работа с базой: `db_users.py` (пользователи), `db_books.py` (книги и лайки), `__init__.py` (класс `Database`, объединяющий их: `db.users`, `db.books`).
- `windows/` — окна приложения, включая окно авторизации `main_window.py`.
- `ui/` — `.ui`-файлы из Qt Designer, `generate_ui/` — сгенерированный из них код.
- `utils/` — вспомогательные скрипты.

## Генерация интерфейса

Код из `generate_ui/` при запуске приложения не обновляется. После изменения любого `.ui`-файла запустите вручную:

```bash
python utils/build_ui.py
```

## Возможности

- Регистрация и авторизация пользователей.
- Анкетирование для определения книжных предпочтений.
- Выбор текущего настроения.
- Персональные рекомендации книг.
- Поиск книг по названию и автору.
- Сохранение понравившихся книг.

В проекте предусмотрен импорт дополнительных книг из CSV в SQLite. При импорте программа проверяет наличие книг в базе, добавляет новые и при необходимости дополняет существующие записи ссылками на обложки.

## Используемые технологии

- Python — основной язык программирования.
- PyQt6 — графический интерфейс.
- SQLite — хранение данных.
- JSON — хранение ответов анкет.
